# Azure AI Developer Prep — Cumulative Build Spine

Portfolio project that grows cumulatively across the Microsoft AI Developer certification path:

- **DP-800** → data and persistence foundation
- **AI-200** → retrieval and orchestration layer
- **AI-103** → production Azure AI integration and hardening

## Target Stack

- **ASP.NET Core minimal API** on **.NET 10**
- **SQL Server 2025** with **vector search**
- **SDK-style SQL Database Projects**
- **Data API Builder** for secure data endpoints
- **RAG** (retrieval-augmented generation) workflow
- **Azure AI services** integration

## Cumulative Phase Plan

### Phase 1 — DP-800 Foundation

- Define the core domain and data model in SQL Server 2025.
- Provision an SDK-style database project and baseline migrations.
- Build minimal API endpoints for core CRUD and ingestion.

### Phase 2 — AI-200 Retrieval Layer

- Add chunking + embedding pipeline into vector-enabled tables.
- Implement retrieval endpoints and grounding contracts.
- Add Data API Builder configuration for data access boundaries.

### Phase 3 — AI-103 Production AI Layer

- Integrate Azure OpenAI / Azure AI services into RAG flows.
- Add evaluation, safety filters, and observability for prompts/responses.
- Harden for deployment with environment-based configuration and ops readiness.

## Outcome

A single, end-to-end certification portfolio backbone that is incrementally expanded rather than rebuilt for each exam.
